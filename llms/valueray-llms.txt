# ValueRay

> Stock screener and financial analysis platform for US equities and ETFs with proprietary ratings, options analytics, dividend screening and structured API access.
> Built for developers creating financial dashboards, analysis tools or trading systems — and optimized for AI/LLM Agents (Agents First) that need structured data to quickly and reliably analyse any symbol.


## About
[ValueRay Overview](https://www.valueray.com/about): Stock screening platform with fundamental, technical and quantitative analysis
[Methodology](https://www.valueray.com/prompts/_explanations.md): Detailed explanation of all proprietary indicators and metrics
[API Documentation](https://www.valueray.com/api): REST API for programmatic access
[OpenAPI Specification](https://www.valueray.com/api/v1/openapi.yaml): Machine-readable REST API schema
[API Metadata](https://www.valueray.com/apis.json): API discovery metadata
